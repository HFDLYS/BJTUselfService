# 交大自由行 KMP 1.8.5-EmergencyFix2（紧急修复）

发布日期：2026-10-20

> 这是一个**紧急修复**版本，包含 EmergencyFix1 的全部修复，并补充课程平台自动回退、Android 小窗账号设置、小组件配色及首页数据变动提醒。学校从 10 月 20 日起更换了 MIS 统一身份认证方式，旧版本无法登录，请尽快更新。

## 本次修复

- **适配 MIS 新认证方式**：登录改为接入学校新的统一身份认证（sso.bjtu.edu.cn），密码按学校页面的方式加密后提交，默认无需验证码；密码错误时就地提示，不再反复重试。退出登录同时注销 MIS 与统一认证。
- **教务系统相关功能正常**：课表、成绩、考试安排等依赖教务系统的功能已恢复。
- **物理在线改用独立账号**：原来经统一认证跳转物理在线的路径已经失效，现改为物理在线自己的账号密码登录。请到「应用 → 设置 → 物理在线账号设置」填写，保存前会真实登录校验，账号密码只存放在系统安全存储中。
- **物理在线升级后自动关闭**：为避免开关开着却无法同步，从旧版本首次升级到本系列紧急修复版本时会自动关闭物理在线，并单独弹窗说明。配置独立账号密码并保存成功后会自动重新打开；已在 EmergencyFix1 完成配置的用户不会再次被自动关闭。
- **版本说明弹窗**：首次进入本系列紧急修复版本会显示紧急修复说明，以及物理在线已自动关闭的提示，均需 3 秒后才可关闭，只显示一次；已在 EmergencyFix1 确认的提示不会重复显示。
- **课程平台增加自动回退**：保留并优先尝试原来的「29.交大课程平台」入口，连接失败时自动经「11.本科教学服务平台 → 智慧课程平台」重新建立会话，用于课程平台作业、课件及课表当前周查询。无需手动切换入口，原入口恢复后仍可直接使用。本次已实际验证作业、课程和课件目录查询。
- **修复 Android 小窗账号设置无法打开**：修复平板小窗或紧凑窗口下，点击「物理在线账号设置」「演示实验账号设置」后页面立即关闭、无法输入账号密码的问题。
- **调整 Android 小组件配色**：针对部分安卓桌面出现课程卡片背景同色、左侧竖条同色的问题，改用各课程类别独立的颜色资源，并修正组件重复刷新时透明度未恢复的问题。
- **补齐首页数据变动提醒**：CITEL、物理实验和演示实验成功更新缓存后，新增、修改或删除的数据也会显示在首页「数据变动」中，点击可进入对应功能。首次同步与切换账号后先建立比较基线，避免把整批数据误报为变化。

## 已知问题

- **课程平台原入口仍异常**：学校原来的直连认证路径仍可能停在旧认证页面，本版本通过本科教学服务平台自动回退；若学校两个入口均不可用，仍会同步失败。本轮未执行真实作业提交、文件上传和附件下载，这些操作尚待验证。
- **新的验证码方式待验证**：新认证系统在特定情况下会要求验证码，目前会转为手动输入，这部分适配尚待实际验证。登录遇到验证码问题请反馈。
- 本版本以紧急修复为主，新功能 **AI-Agent 接入仍在开发中**；其他功能尚未全部重新验证，如遇异常请反馈。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](docs/iOS-sign-guide.md)
- iOS 小组件需要 iOS 17 及以上，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
