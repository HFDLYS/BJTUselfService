# 交大自由行 KMP 1.8.5-EmergencyFix1（紧急修复）

发布日期：2026-10-20

> 这是一个**紧急修复**预发布版本（Pre-release）。学校从 10 月 20 日起更换了 MIS 统一身份认证方式，旧版本无法登录，请尽快更新。

## 本次修复

- **适配 MIS 新认证方式**：登录改为接入学校新的统一身份认证（sso.bjtu.edu.cn），密码按学校页面的方式加密后提交，默认无需验证码；密码错误时就地提示，不再反复重试。退出登录同时注销 MIS 与统一认证。
- **教务系统相关功能正常**：课表、成绩、考试安排等依赖教务系统的功能已恢复。
- **物理在线改用独立账号**：原来经统一认证跳转物理在线的路径已经失效，现改为物理在线自己的账号密码登录。请到「应用 → 设置 → 物理在线账号设置」填写，保存前会真实登录校验，账号密码只存放在系统安全存储中。
- **版本说明弹窗**：首次进入应用会显示本次紧急修复说明，3 秒后才可关闭，只显示一次。

## 已知问题

- **课程平台暂不可用**：学校课程平台的系统迁移尚未完成（仍跳转到已下线的旧认证地址，浏览器访问同样失败），作业和课件下载暂时无法使用，待学校完成迁移后再适配。
- **新的验证码方式待验证**：新认证系统在特定情况下会要求验证码，目前会转为手动输入，这部分适配尚待实际验证。登录遇到验证码问题请反馈。
- 本版本以紧急修复为主，新功能 **AI-Agent 接入仍在开发中**；其他功能尚未全部重新验证，如遇异常请反馈。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](docs/iOS-sign-guide.md)
- iOS 小组件需要 iOS 17 及以上，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
