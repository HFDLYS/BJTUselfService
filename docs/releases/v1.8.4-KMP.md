# 交大自由行 KMP 1.8.4-KMP

发布日期：2026-10-14

新增物理演示实验、iOS 与 Android 桌面课表小组件和第二节错峰上课时间，统一课程配色，并改善同步时的卡顿。

## 更新内容

- **物理演示实验**：在设置中启用并填写演示实验账号后，「应用 → 演示实验」可查看已预约的演示实验，首页“当天实验”和“正在上”也会显示。同步需要校园网。
- **桌面小组件**：iOS 与 Android 新增「临近课程」「今日课程」「本周课表」三种小组件，显示正在上和接下来的课、剩余时间、当天全部课程和整周课表；当天课程上完后显示下一个有课日。支持浅色/深色模式，课表同步后自动更新。
- **错峰上课时间**：第二节在逸夫教学楼、思源西楼的课按 10:30–12:20 显示，课程详情、首页、小组件和日历导出同步调整。默认开启，可在设置中关闭「错峰上课时间」。
- **课程配色统一**：课程表、首页、成绩页和小组件按课程性质（必修/限选/任选/体育/实验/考试）统一配色。
- **首页日程跳转**：物理在线日程跨课程查找后打开详情；CITEL 日程直接进入对应作业详情。
- **课件下载**：标出“未开放下载”的课件并禁用下载；整课批量导出会跳过这些文件并列出，不再整体中断。大文件下载和上传的超时时间放宽。
- **完美校园与校园网缴费**：入口改为二维码弹窗，可“保存二维码并打开微信扫一扫”或复制链接；Android 另可直接打开完美校园 App。
- **HyperOS 小窗**：修复小窗模式下顶栏、底栏和弹窗被拖动条遮挡。
- **iOS 弹窗**：修复关闭弹窗后立即重开偶尔点不开；「前往日期」「课表与周数」「筛选与计算」按内容高度展开。
- **同步更流畅**：学校数据的解析移到后台线程，同步期间滑动不再明显卡顿。
- **新版本提示**：1.8.3 的三个提示弹窗合并为一个；已看过的用户不会再次看到。

演示实验与物理实验需在设置中单独配置账号。物理在线、演示实验同步需要校园网。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](docs/iOS-sign-guide.md)
- iOS 小组件需要 iOS 17 及以上，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。若小组件显示“无法读取课表”，说明签名工具没有保留 App Group，可换用保留扩展的方式重新签名。
- 荣耀手机请在桌面双指捏合 →「桌面卡片」→「经典小工具」中添加小组件，暂不支持荣耀「服务卡片」。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
